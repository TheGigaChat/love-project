# Technical references

## Scroll, playback, and interaction

- Pin a scene while vertical scrolling drives its animation. ScrollTrigger also supports scrubbed timelines that can reverse with the scroll position. [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
- Turn vertical scrolling into a sideways photo sequence. FLOT NOIR explains the pinned track, image clipping, and layout changes in its MERSI walkthrough. [MERSI case study](https://tympanus.net/codrops/2026/07/27/between-print-and-digital-the-making-of-mersis-website/) · [GSAP horizontal scroll demo](https://codepen.io/GreenSock/pen/dyQBdxq)
- Use the element's position in the viewport to drive a CSS animation. The Scroll Storytelling demo uses this for blur and text reveals, and combines a CSS mask with GSAP in its image scene. Its public repo has no detected reuse license. [CSS view timelines](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline/view) · [Scroll Storytelling demo](https://scroll-storytelling-bay.vercel.app/) · [Source for inspection](https://github.com/decriptcypher/scroll-storytelling)
- Study an MIT-licensed example of programmatic scroll with planned stops and a frame sequence. The repository documents how to run it locally. [Osiris source](https://github.com/joelosiris11/osiris-web)
- Review sticky layouts and responsive scrollytelling. Scrollama provides callbacks for when a step enters or leaves view. [Sticky layout guide](https://pudding.cool/process/scrollytelling-sticky/) · [Responsive scrollytelling](https://pudding.cool/process/responsive-scrollytelling/) · [Scrollama](https://github.com/russellsamora/scrollama)
- Try wheel smoothing if the prototype needs it. Lenis also exposes programmatic scrolling. [Lenis](https://github.com/darkroomengineering/lenis)
- Prototype a photo she can move or a title that reveals line by line. [GSAP Draggable](https://gsap.com/docs/v3/Plugins/Draggable/) · [GSAP SplitText](https://gsap.com/docs/v3/Plugins/SplitText/) · [GSAP Flip](https://gsap.com/docs/v3/Plugins/Flip/)

## Inline video and loading

- Use an inline video with a poster, and crop a round note with CSS. Start and pause from scene entry and exit. Test audible playback on the intended phone because browser autoplay rules can block it. [MDN video](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video) · [Object fit](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-fit) · [Autoplay guide](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) · [WebKit video policy](https://webkit.org/blog/6784/)
- Prioritize the cover and first scene. Load later media near its scene, using a poster or fixed dimensions to preserve the layout. [MDN lazy loading](https://developer.mozilla.org/en-US/docs/Web/Performance/Guides/Lazy_loading) · [Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API) · [HTML performance guide](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Performance/HTML)
